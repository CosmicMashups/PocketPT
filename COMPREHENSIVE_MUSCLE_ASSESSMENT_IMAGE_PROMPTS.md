# Comprehensive AI Image Generation Prompts for Muscle Assessment Poses

This document provides AI-engineered prompts for Google Gemini to generate reference images showing expected poses for each pain scale category (Low, Moderate, Severe) across all muscle assessments in the PocketPT application.

## 1. BICEPS ASSESSMENT

### Assessment Logic
- **Measurement**: Shoulder-Elbow-Wrist angle
- **Severe** (Extended): Angle > 150° - Poor flexion, arm extended
- **Moderate**: 90° < angle ≤ 150° - Partial flexion
- **Low** (Good): Angle ≤ 90° - Good flexion, arm well bent

### Landmarks used
- shoulder (side-specific)
- elbow (side-specific)
- wrist (side-specific)

### Severe Pain Prompt (Extended Arm)
```
Generate a professional medical illustration of a person standing in profile view performing a biceps ROM assessment pose showing SEVERE limitation. The person's right arm should be extended nearly straight downward (elbow angle > 150 degrees between shoulder, elbow, and wrist). Show minimal elbow flexion indicating poor biceps flexibility. The person stands in neutral position with the affected arm hanging down with very little bend at the elbow. Medical/clinical illustration style with clean white background. Side view clearly showing shoulder-to-wrist alignment. Professional anatomical drawing aesthetic.
```

### Moderate Pain Prompt (Partially Flexed)
```
Generate a professional medical illustration of a person standing in profile view performing a biceps ROM assessment pose showing MODERATE limitation. The person's right arm should be partially bent at the elbow (angle between 90-150 degrees). Show moderate elbow flexion indicating partial biceps ROM restriction. The person stands in neutral position with the affected arm bent at approximately 60-90 degrees at the elbow joint. Medical/clinical illustration style with clean white background. Side view clearly showing shoulder-to-wrist alignment. Professional anatomical drawing aesthetic.
```

### Low Pain/Good ROM Prompt (Well Flexed)
```
Generate a professional medical illustration of a person standing in profile view performing a biceps ROM assessment pose showing GOOD/NORMAL ROM. The person's right arm should be well flexed at the elbow (angle < 90 degrees). Show significant elbow flexion with the hand close to the shoulder, indicating healthy biceps flexibility and strength. The person stands in neutral position with the affected arm bent significantly at the elbow (close to full flexion). Medical/clinical illustration style with clean white background. Side view clearly showing shoulder-to-wrist alignment. Professional anatomical drawing aesthetic.
```

## 10. CALVES ASSESSMENT

### Assessment Logic
- **Measurement**: Normalized displacement (knee-to-ankle horizontal distance / body segment height)
- **Severe**: < 0.15 - Minimal forward knee movement, severe dorsiflexion limitation
- **Moderate**: 0.15 ≤ displacement < 0.30 - Partial forward movement
- **Good**: ≥ 0.30 - Good forward knee movement over ankle

### Landmarks used
- hip (side-specific) – used for vertical body segment height with ankle
- knee (side-specific) – used for horizontal displacement vs ankle
- ankle (side-specific)
- Alignment cue: knee relative to ankle ("knee forward" vs "behind/inline")

### Severe Pain Prompt (Knee Behind Ankle)
```
Generate a professional medical illustration of a person standing in profile view performing a calf dorsiflexion assessment pose showing SEVERE limitation. The person's right leg should have the knee positioned behind or barely over the ankle (knee-to-ankle displacement < 0.15x body height). The knee is far from being forward over the ankle, indicating severe calf tightness and dorsiflexion limitation. The person stands in lunge position with back leg showing severe limitation. Medical/clinical illustration style with clean white background. Side view clearly showing knee-to-ankle alignment. Professional anatomical drawing aesthetic.
```

### Moderate Pain Prompt (Knee Partially Forward)
```
Generate a professional medical illustration of a person standing in profile view performing a calf dorsiflexion assessment pose showing MODERATE limitation. The person's right leg should have the knee positioned partially over the ankle (knee-to-ankle displacement 0.15-0.30x body height). The knee shows moderate forward movement, indicating moderate calf flexibility limitation. The person stands in lunge position. Medical/clinical illustration style with clean white background. Side view clearly showing knee-to-ankle alignment. Professional anatomical drawing aesthetic.
```

### Good ROM Prompt (Knee Well Forward)
```
Generate a professional medical illustration of a person standing in profile view performing a calf dorsiflexion assessment pose showing GOOD/NORMAL ROM. The person's right leg should have the knee positioned well forward over the ankle (knee-to-ankle displacement ≥ 0.30x body height). The knee shows significant forward movement beyond the ankle, indicating good calf flexibility and dorsiflexion. The person stands in lunge position with good knee-forward positioning. Medical/clinical illustration style with clean white background. Side view clearly showing knee-to-ankle alignment. Professional anatomical drawing aesthetic.
```

## Consistency Guidelines

All prompts follow these design principles:
- Professional medical illustration style
- Clean white background
- Clear anatomical landmarks visible
- Side or front views as appropriate for measurement
- Neutral, clinical aesthetic
- Specific angle measurements included
- Clear indication of limitation level
