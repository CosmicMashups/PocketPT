## Why

The current recording interface pages (confirm_save_page.dart, cooldown_stretching_page.dart, pre_record_page.dart, record_exercise.dart) and supporting services have a basic design that lacks visual appeal and professional aesthetics. While functional, these pages need enhanced colors, icons, and visual elements to create a more engaging and professional user experience that matches medical-grade application standards.

## What Changes

- **Enhanced Color Palette**: Expand the design system with additional medical-grade colors, gradients, and accent colors
- **Icon Integration**: Add meaningful icons throughout the interface for better visual hierarchy and user guidance
- **Visual Enhancements**: Improve shadows, borders, animations, and micro-interactions
- **Professional Aesthetics**: Maintain medical-grade professionalism while adding visual appeal
- **Consistent Theming**: Ensure all recording-related pages follow the same enhanced design language
