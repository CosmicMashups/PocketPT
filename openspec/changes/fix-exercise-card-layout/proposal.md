## Why
The exercise cards in the exercise list are cluttered and the "Select" button is overlapping with other elements. The current layout is not optimized for Android smartphone dimensions, making it difficult for users to interact with the cards effectively.

## What Changes
- Redesign exercise card layout to be less cluttered
- Fix "Select" button positioning to prevent overlapping
- Optimize card dimensions for Android smartphone screens
- Improve spacing and visual hierarchy
- Ensure proper touch targets for mobile interaction

## Impact
- Affected specs: exercise-management (modified capability)
- Affected code: lib/exercise/exercise_list.dart
- Users will have a better experience browsing and selecting exercises on Android devices
